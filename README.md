# Session 09-10 - Personal Web Project

**Student:** Richa Shrivastava  
**ID:** 25bcon1642

An original responsive personal portfolio with a profile page, CSS theme variables, light/dark mode, and a five-question JavaScript quiz.

## Files
- `index.html` - landing page
- `personal_profile.html` - profile
- `quiz.html` - interactive quiz
- `assets/style.css` - styling and theme variables
- `assets/script.js` - theme toggle and quiz logic

## Run
Use a local server rather than opening the files directly with `file://`.

For example:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

# Website Testing Checklist

- [ ] Home page loads on desktop.
- [ ] Profile page loads.
- [ ] Quiz presents five questions.
- [ ] An answer cannot be counted twice by repeated clicks.
- [ ] Final score is displayed after question five.
- [ ] Theme toggle changes light/dark mode.
- [ ] Theme persists after refresh.
- [ ] Layout remains usable around 375px wide.
- [ ] Browser console has no errors.
- [ ] Site is run through a local server.
